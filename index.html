// Featured Project

AI-ization of Customer Support

AI Integration • RAG • LLM Workflows • MCP

AI-Powered Customer Support for Students and Teachers

Reducing inquiry wait time through immediate, context-aware AI support across NativeCamp student and home-based teacher portals

Objective

Build an AI-powered Customer Support system for both NativeCamp students and home-based teachers. The system provides immediate RAG-based answers, uses backend context for account-specific decisions, and encourages adoption of AI support over traditional inquiry channels.

Technology Stack

Dify AI RAG MCP Server PHP Backend Vue.js MySQL Context LLM Workflows Chatflow API

Implementation

Knowledge Preparation

Scraped and structured official NativeCamp content including usage pages, FAQ, announcements, campaign information, and teacher support materials. Populated datasets into Dify Knowledge Base for high-precision RAG responses.

Dual Chatflow Creation

Implemented separate Dify chatflows for student/user CS and teacher/tutor CS. Used LLM, routing, decomposition, answer formatting, and unresolved-case handling for support scenarios.

MCP-Backed User Context

Added a user-side MCP server path that retrieves database context for the AI workflow. This allows the system to determine NativeCamp coin refund eligibility before generating refund guidance.

Teacher Support Flow

Extended AI Support to home-based teachers with a teacher-side CS page and tutor-oriented chatflow for FAQ, troubleshooting, lesson, account, and operational inquiries.

Access Control

Student AI Support is limited to eligible logged-in users such as premium plan holders and JPY currency users. Teacher AI Support is available through authenticated teacher support pages.

The CS team monitors only escalated unresolved cases; routine interactions are handled automatically.
